a video demonstration of the game is available on You-Tube at: https://youtu.be/TyCfieVgAxI

This game was made using CPUlator, at this link: https://cpulator.01xz.net/?sys=arm-de1soc

The push buttons move the character, Up, Left, Down, and Right. The game is visible in the pixel buffer. 
Before starting the game, bring the the two tabs that say push button and pixel puffer together make the game much easier to play.

the goal of the game is to get the bird character to the right side, and you get to the next 
level by touching the right side of the screen. There are moving obstacles you have to avoid while doing this.
